# ❤️ Heart Disease Prediction App

🚀 **Live App:**
👉 https://heart-disease-predictor-dhg7yyxpbd8zj2yknzxd9aaabb.streamlit.app/

---

## 📌 Overview

This project is a **Machine Learning-powered web application** that predicts the likelihood of heart disease based on patient health parameters.

It is built using **Python, Scikit-learn, and Streamlit**, and deployed for real-time usage.

---

## 🧠 Features

* 🔍 Predict heart disease risk instantly
* 📊 Interactive dashboard with risk visualization
* 🎯 Clean and user-friendly interface
* ⚡ Real-time predictions using trained ML model
* 📈 Probability score with confidence

---

## 🛠️ Tech Stack

* **Python**
* **Pandas & NumPy**
* **Scikit-learn**
* **Streamlit**
* **Joblib**
* **Plotly**

---

## 🤖 Machine Learning Model

* Algorithm Used: **K-Nearest Neighbors (KNN)**
* Data preprocessing:

  * Handling missing values
  * Feature encoding
  * Feature scaling
* Model evaluation:

  * Accuracy ~80%

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/tawheed7mir-ai/heart-disease-predictor.git
cd heart-disease-predictor
```

2. Install dependencies:

```
pip install -r requirements.txt
```

3. Run the app:

```
streamlit run app.py
```
